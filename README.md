# 포커스 플래너

공기업 준비생 캐릭터를 키우며 기상, 오늘의 목표, 뽀모도로 집중을 기록하는 RPG 플래너입니다.
휴대폰 홈 화면에 추가하면 앱처럼 전체 화면으로 열리고, 인터넷 없이도 동작합니다.

## 파일 구성

- `index.html`: 앱 전체 (화면, 게임 규칙, 저장)
- `manifest.webmanifest`: 앱 이름, 아이콘, 전체 화면 설정
- `sw.js`: 오프라인 실행과 업데이트 알림
- `icon-*.png`, `maskable-512.png`, `apple-touch-icon.png`: 홈 화면 아이콘

## 올리는 법 (GitHub Pages)

1. GitHub에서 새 저장소 `focus-planner`를 만들고 이 폴더의 파일을 모두 올립니다.
2. 저장소 Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 정하고 저장합니다.
3. 1~2분 뒤 `https://아이디.github.io/focus-planner/` 주소로 열립니다.
4. 휴대폰에서 그 주소를 열고 홈 화면에 추가합니다.
   - 아이폰: Safari 공유 버튼 → 홈 화면에 추가
   - 안드로이드: Chrome 메뉴 → 앱 설치

## 새 버전 올리기

`index.html`을 고친 뒤 `sw.js`의 `VERSION` 값을 바꿔서 함께 올립니다 (예: `fp-1.0.1`).
앱을 열면 '새 버전이 준비됐어요' 알림이 뜨고, 누르면 적용됩니다. 기록은 그대로 남습니다.
